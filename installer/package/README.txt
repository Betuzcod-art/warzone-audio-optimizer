WARZONE AUDIO OPTIMIZER - INSTALACION

1. Ejecuta el instalador descargado como administrador.
2. Completa la instalacion del driver VB-CABLE cuando te lo pida.
3. Reinicia Windows tras instalar el driver.
4. En Warzone, selecciona como salida de audio:
   CABLE Input (VB-Audio Virtual Cable)
5. Deja tus auriculares/altavoces fisicos como salida predeterminada de
   Windows.
6. Abre Warzone Audio Optimizer y pulsa ACTIVAR PROCESAMIENTO.

La aplicacion cae automaticamente a la salida predeterminada de Windows si
el equipo no tiene un endpoint Realtek.

Aviso de SmartScreen ("Editor desconocido"):
Este instalador no tiene certificado de firma de codigo comercial, asi que
Windows puede mostrar ese aviso la primera vez. No significa que el archivo
este danado -- puedes verificar el checksum SHA-256 publicado junto al
Release en GitHub contra el archivo descargado antes de ejecutarlo.

Reparar:
Vuelve a ejecutar el instalador -- sobrescribe los archivos de la app. Si
detecta una instalacion previa, te preguntara si tambien quieres reinstalar
el driver VB-CABLE (normalmente no hace falta si ya funciona).

Desinstalar:
Usa "Aplicaciones y caracteristicas" o ejecuta uninstall.cmd desde la
carpeta instalada.

VB-CABLE:
Este paquete incluye VB-CABLE, un driver de audio virtual donationware de
VB-Audio (www.vb-cable.com). Si te resulta util, considera donar en
vb-audio.com.
